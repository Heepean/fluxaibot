# Process & Model Manager

- Один активный inference runtime в MVP; архитектура допускает несколько позже.
- Не запускать две копии одного профиля без явного подтверждения.
- Очередь операций Start/Stop/Load/Unload сериализована; отмена безопасна.
- Состояние восстанавливать после аварийного завершения приложения.
- Проверять stale PID и executable identity до любого terminate.
- Сохранять runtime logs с ограничением размера и ротацией.
- Не удалять и не перемещать модели без отдельного подтверждения.
- При смене модели: graceful stop → новая модель → readiness → smoke test; при неудаче вернуть предыдущий профиль и попытаться восстановить предыдущую модель.
- Предусмотреть memory pressure warning; не пытаться автоматически закрывать сторонние приложения.
